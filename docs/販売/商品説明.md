## これは何？

Claude Code（Anthropic の AI コーディング道具）を、プログラムを知らない人でも安心して使えるようにする日本語のプラグインです。入れると画面がこう変わります。

- **帯**: いま Claude が何をしているか、待っていていいかを、猫の顔文字つきで入力欄の上に 1 行出します。あなたの番なら黄色。
- **実況**: 回っているスピナーが「hooks/activity.tsx を読んで、ロゴの描画位置を探してます（12s）」のように、動作・対象・目的・経過時間を日本語で出します。
- **許可とエラーの翻訳**: 「許可しますか？」やエラー文を、やさしい日本語 3 行に。あなたがやることがある時（ログイン・鍵・権限・道具の未インストール）だけ、それを 1 行で。
- **見張り**: 秘密の鍵の直書き、.env のコミット、公開リポジトリの作成、本番への破壊操作を機械的に止めます。AI は使いません。
- **操作盤（右のペイン）**: おねがい・読む・戻す・おわり・点検・もっと簡単に・確認して をボタンで。
- **自動バックアップ**: 危ない変更の前に控えを取り、「戻す」から戻せます。
- **3 行まとめ**: ひと区切りごとに「やったこと／確認の仕方／次にやること」。
- **雰囲気モード**: 琥珀色の HUD（文脈の使用率、30 秒ごとのトークン量、動いている道具の脈動表示）と起動ロゴ。数字は全部実データ。

## 動作環境

- macOS、Claude Code 2.1.285 以降（Function Hooks 対応版）で動作確認
- Claude Code は別途必要です（本商品には含まれません）
- Claude Code 本体のバージョンアップで動かなくなる可能性があります。その場合の修正は行いません

## インストール（zip を展開したフォルダで）

```bash
claude plugin marketplace add ./tamacode
claude plugin install tamacode@tamacode-marketplace
```

Claude Code の中で `/tama` と打つと帯とペインが開きます。使い方の全部は同梱の README.md にあります。

## 自分で直せる人向けに

文言は `locales/ja.json`、見張りの規則は `rules/security.json`、雰囲気モードの色や行数は `config/vibe.json` を書き換えるだけで変わります。コードは `hooks/` の下にあり、どのファイルが何をしているかは README に表があります。テストは `claude plugin test .` で回ります。
